# 🚀 JanHacks 2027

Welcome to **JanHacks 2027**! Start 2027 by building something you're genuinely proud of. With **no theme** and **two full months** on the clock, this hackathon is all about learning, experimenting, and turning your coolest ideas into real, working projects—without the stress of a 48-hour all-nighter. 

Whether this is your very first hackathon or you're an experienced teen builder, you're in the right place!

# 🎓 Who Can Join (Eligibility)

JanHacks 2027 is built specifically for young makers and student developers: 

* **Ages 13–18 Only:** All participants must be between **13 and 18 years old** at the start of the hackathon.
* **Students Only:** You must be currently enrolled in middle school, secondary/high school, or an equivalent student program (including homeschooled students).
* **No Companies or Professionals:** Companies, agencies, commercial startups, and professional/adult organizations are strictly excluded from participating. All projects must be built independently by eligible students.

# 💡 Theme

**Open-Ended (No Theme!)**
Build whatever excites you most. A website, an indie game, a Discord bot, a CLI tool, an AI project, a mobile app, or a cool piece of creative coding—if you want to build it, it fits. 

# 📜 Rules & Guidelines

1. **Eligibility Check:** Every member of your team must meet the **13–18 student-only** eligibility rules above.
2. **Build During the Event:** Start your code and designs on or after **January 1, 2027 at 00:00 UTC**. Using open-source libraries, game engines, frameworks, and public APIs is completely fine!
3. **Solo or Team:** Work by yourself or team up with up to **4** eligible students.
4. **Open Source:** Host your project in a public repository (like GitHub or GitLab) with a README explaining what it does and how to run it.
5. **Keep It Friendly:** Be kind, respectful, and helpful to other participants. No spam, plagiarism, or NSFW content.

# 📦 How to Submit

Submit your project before **March 1, 2027 at 23:59 UTC** via **[Insert Submission Form / GitHub Issues Link]** with: 

* **Source Code:** Link to your public repo.
* **Short Demo:** A quick video (1–3 minutes) or screenshots/GIFs showing your project in action.
* **Project Summary:** What you built, what tools/languages you used, and what you learned along the way.
* **Live Link (Optional):** A hosted site or downloadable build if applicable.

# Main Awards

1. **Grand Champion (1st Place Overall)** – Top score across all categories.
2. **Runner-Up (2nd Place Overall)** – Second highest overall score.
3. **3rd Place Overall** – Third highest overall score.
4. **Community Choice Award** – Voted on by fellow participants.

# Project Type Awards

1. **Best Web App** – Cleanest, most useful website or web platform.
2. **Best Indie Game** – Most fun, addictive, or well-crafted game.
3. **Best AI / Machine Learning Project** – Coolest or smartest use of AI/LLMs.
4. **Best Developer Tool / CLI** – Best utility, library, terminal app, or extension.
5. **Best Bot / Automation** – Best Discord bot, Telegram bot, or workflow automation.
6. **Best Mobile App** – Best iOS, Android, or cross-platform mobile build.

# Craft & Vibe Awards

1. **Best UI / UX Design** – Most polished interface and smoothest user experience.
2. **Most Technically Complex** – Hardest engineering challenge pulled off cleanly.
3. **Most Creative / Weirdest Idea** – For the project nobody else would ever think of.
4. **Best Retro / Minimalist Project** – Coolest project built with low-level tech, pixel art, or ultra-clean simplicity.
5. **Best Open-Source Contribution** – Best documentation, clean code, and reusable architecture.

# Builder & Milestone Awards

1. **Best First-Time Hacker** – For someone participating in their very first hackathon.
2. **Best Solo Build** – Built completely by one person from scratch.
3. **Best Junior Builder (Ages 13–14)** – Top project built by younger middle/early-high-school coders.
4. **Most Improved / Best Devlog** – Best journey documented over the two months.
5. **"Actually Useful" Award** – A tool you'd genuinely use every single day.

# 📊 Judging Criteria

Projects will be judged on: 

* **Creativity:** How fun, clever, or original is the idea?
* **Execution:** Does it work well? How much effort and polish went into it over the two months?
* **Tech & Craft:** Cool technical challenges solved or great design/user experience.
* **Fun / Usefulness:** Is it enjoyable to use or helpful to others?
